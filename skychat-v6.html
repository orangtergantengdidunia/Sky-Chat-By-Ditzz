🔥 Tutorial: Simpan Email & Password di Firebase

Panduan lengkap cara menyimpan data member ke Firebase Realtime Database & Auth.

1

Aktifkan Firebase Authentication

Di Firebase Console → Authentication → Sign-in method → Email/Password → Enable.

2

Struktur Database Members

Data member tersimpan di path members/{uid} di Realtime Database:

{ "members": { "UID_user": { "displayName": "Nama User", "email": "user@email.com", "createdAt": 1700000000000, "verifiedAt": 1700000000000 } } }
3

Aturan Database (Rules)

Di Firebase Console → Realtime Database → Rules, tambahkan:

{ "rules": { "members": { "$uid": { ".read": "$uid === auth.uid", ".write": "$uid === auth.uid" } }, "admins": { ".read": "auth != null", ".write": false } } }
4

Kode Registrasi Member

Saat member daftar, Firebase Auth menyimpan email+password secara aman (terenkripsi), dan data profil disimpan ke Realtime Database:

auth.createUserWithEmailAndPassword(email, password) .then(cred => { const uid = cred.user.uid; // Kirim email verifikasi cred.user.sendEmailVerification(); // Simpan profil ke database db.ref('members/' + uid).set({ displayName: nama, email: email, createdAt: Date.now() }); });
5

Kode Verifikasi Email

Setelah daftar, cek apakah email sudah diverifikasi sebelum login:

auth.signInWithEmailAndPassword(email, password) .then(cred => { if (!cred.user.emailVerified) { auth.signOut(); alert('Verifikasi email dulu!'); return; } // Lanjut login... });
6

Lihat Daftar Member di Console

Firebase Console → Authentication → Users → terlihat semua email terdaftar. Untuk data tambahan (nama, dll) lihat di Realtime Database → members.
